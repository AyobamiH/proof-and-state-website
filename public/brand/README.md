# Proof & State brand assets

This directory contains the canonical website-owned Proof & State identity assets.

## Mark

The current mark is an Evidence Industrialism treatment of the Proof & State symbol:

- carbon / graphite rails: separated system boundaries
- blue: AgentProof / information and receipt layer
- green: independent verification
- orange: DoneState execution
- paper background: the website's material base

The website UI renders the same geometry from `src/components/ps/brand.tsx` so material
colours inherit light/dark theme tokens. Static favicon and platform assets use the
light paper palette for predictable rendering outside the application.

Do not replace these files with Lovable-generated branding or an unrelated scaffold icon.
